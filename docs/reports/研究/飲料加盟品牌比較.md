## 三、詳細品牌分析

### 🥤 五十嵐

- **店數：** 全台約600家

- **劣勢：** 市場競爭激烈、部分區域已飽和
- **適合：** 追求穩健經營的創業者

### 🥤 清心福全
- **店數：** 全台超過950家（門市數量冠軍）

- **劣勢：** 店數過多可能稀釋單店營收

## 四、創業總成本預估

開一家手搖飲店的**總成本**大概如下：

| 項目 | 費用範圍 |
|------|---------|
| 加盟金（含訓練、規劃） | 150萬～600萬 |
| 裝潢工程 | 約50萬～100萬（視店面大小） |
| 設備（POS、封口機、製冰機等） | 約30萬～60萬 |
| 店面押金＋租金（視地段） | 未知（差異大） |
| 原料進貨 | 約5萬～10萬 |
| 申請設立（公司登記） | 約1萬～5萬 |
| **總計** | **約200萬～800萬** |

> 💡 業界建議：租金最好控制在預期總營收的10%~15%以內

## 五、加盟 vs 自創品牌

| 項目 | 加盟 | 自創 |
|------|------|------|
| 創業成功率 | 較高（有成功模式） | 僅1% |
| 成本 | 較高（需付加盟金、權利金） | 較低（但失敗率高） |
| 品牌支援 | 有總部支援 | 無 |
| 利潤空間 | 較低（需分潤） | 較高（無需分潤） |
| 彈性 | 受合約束縛 | 完全自由 |

## 六、給老闆的建議

1. **資金有限（200萬以下）：** 考慮「得正」（約150萬起），或考慮二手設備降低設備成本
2. **追求穩健：** 五十嵐或清心福全，知名度高、成功模式可循
3. **產品差異化：** 麻古茶坊、迷客夏、五桐號 - 各有特色茶飲
4. **資金充裕想走高端：** 八曜和茶（600萬）
5. **沒有單店加盟：** COMEBUY需要有多店開發能力
