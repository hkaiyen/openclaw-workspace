# 飲料店組長面談重點

## 一、面談核心目的

面談是為了確認候選人是否具備：
1. **能力** - 能不能做好這份工作
2. **態度** - 願不願意投入、學習
3. **價值觀** - 與你的理念是否契合
4. **承諾** - 是否願意長期投入

---

## 二、必問的5大問題

### 問題1：經歷與經驗
```
「請分享過去在餐飲或零售業的工作經驗？」
「在過往工作中，處理過最困難的情況是什麼？」
```

**評估重點**：
- 是否有2年以上餐飲或零售經驗
- 能否具體描述工作內容與成就
- 遇到問題時的解決方式

---

### 問題2：對於飲料店的熱情
```
「你平常有喝手搖飲的習慣嗎？最喜歡哪家？」
「為什麼想加入飲料店這個行業？」
「你覺得這行最吸引你的地方是什麼？」
```

**評估重點**：
- 對飲料店是否有熱情
- 是否了解這個行業的辛苦
- 動機是否正面（想學習vs只是想找個工作）

---

### 問題3：壓力處理能力
```
「飲料店尖峰時段非常忙，客人排隊又催單，
你會怎麼面對壓力？」
「如果遇到奧客或客訴，你會怎麼處理？」
```

**評估重點**：
- 面對壓力時的反應
- 情緒管理能力
- 處理衝突的方式

---

### 問題4：團隊與管理
```
「你有帶過新人嗎？你是怎麼訓練的？」
「如果你的同事態度消極，你會怎麼處理？」
「你覺得一個好的組長應該具備什麼條件？」
```

**評估重點**：
- 是否有領導經驗
- 管理風格
- 對組長角色的理解

---

### 問題5：未來規劃與承諾
```
「你希望在這個工作上待多久？」
「如果店裡忙的時候需要加班或假日上班，你能接受嗎？」
「你的長期 career 規劃是什麼？」
```

**評估重點**：
- 是否願意長期投入
- 對未來的規劃
- 工作與生活的取捨

---

## 三、觀察重點（非言語線索）

### 態度觀察
- 面試時是否準時到達
- 穿著是否整潔（不能穿拖鞋）
- 態度是否積極、有熱情
- 眼神是否專注、诚恳

### 肢體語言
- 說話時是否眼神游移
- 回答問題是否拖泥带水
- 肢體語言是否自信、從容

### 誠信觀察
- 過往經歷是否過度包裝
- 說謊時的小動作（眼神飄移、說話變快）

---

## 四、情境題演練

### 情境1：高峰期出錯
```
「假設你正在做一杯飲料，旁邊同事出錯了，
導致這杯要重做，但客人已經在催了，
你會怎麼處理？」
```

**理想回答**：
- 先安撫客人，誠實告知等待時間
- 加快速度補足，同時檢視流程
- 事後檢討，避免再犯

---

### 情境2：組員想跳槽
```
「假設你的組員跟你说想離職，
你會怎麼處理？」
```

**理想回答**：
- 了解原因（錢少？太累？沒有發展？）
- 嘗試解決可改善的問題
- 無法改善時，尊重決定並祝福

---

### 情境3：原物料用完
```
「假設某項原物料突然用完，但供應商明天才能送，
你會怎麼處理？」
```

**理想回答**：
- 與顧客溝通，提供替代方案
- 臨時調貨或從其他分店支援
- 記錄教訓，未來做好安全存量

---

## 五、必須確認的基本條件

### 工作意願
- [ ] 能配合假日及節日工作（飲料店假日最重要）
- [ ] 能接受輪班制
- [ ] 能配合長期站立工作

### 交通能力
- [ ] 具備機車或汽車駕照
- [ ] 住在店面方圓30分鐘內

### 財務狀況
- [ ] 能否提出一定比例資金入股
- [ ] 沒有過多負債影響判斷

---

## 六、黑名單（遇到就跳過）

1. **履歷過度包裝** - 說得比做得厲害
2. **態度惡劣** - 對店員或面試官不禮貌
3. **只重視錢** - 開口就問待遇，不問工作內容
4. **沒有熱情** - 問什麼都說「都可以」
5. **負能量重** - 一直抱怨前公司

---

## 七面談結尾的問題

```
「你對這個職位有什麼問題想問我嗎？」
```

**這個問題的答案很重要**：
- 問很多問題 → 積極主動
- 說「沒有」→ 可能只是來找工作的
- 問什麼 → 可以看出他的價值觀

---

## 八、面談後的動作

1. **24小時內**決定是否錄取
2. **參考資料**打電話確認過去工作表現
3. **背景調查**確認經驗真實性
4. **試用期**設定一個月觀察期

---

**面談地點建議**：
- 飲料店現場最好（可以看到實際環境）
- 選擇下午3-5點或晚上7點後（避開高峰期）
