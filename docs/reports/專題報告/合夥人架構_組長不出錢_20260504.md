# 🧋 手搖飲事業合夥人架構（組長不出錢版本）

## 老闆目標：當投資者，適度介入，不親自經營

---

## 問題來了：組長不出錢怎麼辦？

組長如果不出資，嚴格來說是「員工」而非「合夥人」。

但老闆需要的是：一個願意長期投入、全力以赴的經營者。

所以要用「激勵機制」取代「資金綁定」。

---

## 調整後的架構

### 角色定義

| 角色 | 稱呼 | 出資 | 責任 |
|------|------|------|------|
| 老闆 | 投資者 | 100% | 提供資金、品牌、策略 |
| 組長 | 經營者 | 0% | 實際營運管理，承擔責任 |

---

## 激勵機制設計

### 1. 底薪 + 績效獎金

| 項目 | 說明 |
|------|------|
| 底薪 | 基本生活保障（參考市場行情） |
| 營運獎金 | 達成營收目標後的額外獎金 |
| 分紅 | 盈餘的一定比例（替代出资） |

**建議比例**：
- 營收獎金：每月營收超過目標的10-20%作為獎金
- 盈餘分紅：30%盈餘讓組長分紅（替代资金投入）

### 2. 為什麼要這樣設計？

沒有出资就沒有「皮膚在遊戲中」的綁定感。

但如果：
- 組長賺得比一般員工多很多
- 組長的未來與店鋪成長綁定
- 表現好可以參與更多分紅

這也能激勵組長全力以赴。

---

## 權責分工

### 老闆的責任

- 提供所有營運資金
- 提供品牌與know-how
- 設定營運目標與KPI
- 每週查看報表
- 每月實地巡店
- 每季深度檢討

### 組長的責任

- 實際店鋪營運（每日開店、閉店）
- 人員管理（雇用、訓練、考核）
- 原物料管理（叫貨、庫存、成本控制）
- 顧客服務與客訴處理
- 每日結算、帳務管理
- 行銷活動執行

---

## 老闆介入時機

### 應該介入

| 時機 | 內容 |
|------|------|
| 每週一 | 查看上週營收報表 |
| 每月 | 實地巡店1-2次 |
| 每季 | 與組長深度檢討策略 |
| 每年 | 規劃是否展店 |
| 緊急 | 單筆支出超過3萬、設備故障 |

### 不應該介入

| 時機 | 內容 |
|------|------|
| 日常 | 排班安排、原物料叫貨 |
| 員工 | 獎懲決定、態度問題 |
| 顧客 | 現場客訴處理 |
| 行銷 | 活動執行方式 |

---

## 保障機制（沒有出资的替代方案）

### 1. 績效綁定

```
前3個月：密集觀察期
- 設定明確KPI（營收、毛利、客訴率）
- 達成才能繼續擔任組長

第4個月起：正式任期
- 每季重新確認營運目標
- 連續2季未達標，終止合作
```

### 2. 競業禁止

組長在合作期間及合作結束後1年內：
- 不得經營同類型飲料店
- 不得加入竞争对手
- 違者需賠償

### 3. 保密協議

組長不得對外透露：
- 配方、原料來源
- 營運策略、成本結構
- 顧客資料

---

## 退出機制

### 組長想退出
- 提前30天書面告知
- 完成工作交接
- 按實際表現發放應得獎金

### 老闆想結束
- 提前60天告知
- 發放資遣費（1個月底薪）
- 協商過渡期安排

### 特殊情況
- 嚴重違規：可立即終止
- 營收連續6個月下滑：重新檢討合作模式

   - 保密義務
   - 競業禁止範圍與期限

   - 退出程序
   - 預告期
   - 資遣費計算

## 總結

| 項目 | 原本規劃 | 調整後 |
|------|----------|--------|
| 組長出资 | 20%（10-20萬） | 0 |
| 組長回報 | 盈餘分紅30% | 底薪 + 營運獎金 + 盈餘分紅 |
| 利益綁定 | 出资 | 績效獎金 + 競業禁止 |
| 老闆介入 | 適度 | 每週看錶、每月巡店 |

**核心問題**：組長不出資，忠誠度怎麼辦？

**答案**：用績效綁定、用獎金激勵、用競業禁止保護。
