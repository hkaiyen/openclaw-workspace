# 飲料店/手搖飲門市店长能力模型研究報告

**整理日期：2026年5月4日**
**用途：尋找合作夥伴擔任店長**

---

## 一、產業背景與挑戰

### 手搖飲市場現況
- 台灣手搖飲店家數：23,849家（2019年），產值達994億元
- 全球市場規模預計2027年達43億美元，年複合成長率7.8%
- 進入門檻不高，但競爭激烈，每年約有70%餐飲業倒閉

### 經營者面臨的核心挑戰
1. **原物料成本上漲** - 茶葉、奶、糖、包材價格波動
2. **人力資源稀缺** - 流動率高，難以找到穩定員工
3. **消費者忠誠度下降** - 平均消費頻率縮短
4. **市場饱和** - 街頭巷口都是競爭對手
5. **食安風險** - 任何食安事件都可能是致命打擊

## 二、店長能力模型（5大核心能力）

### 能力一：營運管理能力

| 能力項目 | 說明 |
|---------|------|
| 標準化流程執行 | 確保每杯飲料品質一致，符合SOP |
| 庫存管理 | 精準掌握原物料，避免浪費或缺貨 |
| 成本控制 | 了解每項原物料成本，優化損耗 |
| 人力排班 | 有效調度員工，高峰時段人力充足 |
| 設備維護 | 日常保養，延長設備壽命 |

**關鍵指標**：出品速度、錯誤率、損耗率

---

### 能力二：銷售與顧客服務能力

| 能力項目 | 說明 |
|---------|------|
| 顧客需求洞察 | 了解在地顧客口味偏好 |
| 問題處理 | 快速有效處理客訴 |
| 促銷執行 | 配合總部行銷活動 |
| 會員經營 | 建立穩定回購顧客群 |
| 社群互動 | 適時在社群媒體與顧客互動 |

**關鍵指標**：顧客滿意度、回購率、客單價

---

### 能力三：領導與團隊管理能力

| 能力項目 | 說明 |
|---------|------|
| 員工訓練 | 新人帶訓、標準化教育 |
| 激勵團隊 | 維持員工士氣與向心力 |
| 異常處理 | 面對突發狀況冷靜應對 |
| 傳承複製 | 能培養出第二梯隊幹部 |
| 跨店支援 | 緊急時能調配資源 |

**關鍵指標**：員工流動率、訓練完成率

---

### 能力四：應變與危機管理能力（韌性）

| 能力項目 | 說明 |
|---------|------|
| 快速學習 | 新產品、新技術能快速上手 |
| 市場感知 | 觀察競爭對手動態並回應 |
| 庫存風險 | 供應鏈中斷時能靈活應對 |
| 食安緊急應變 | 遇到問題能迅速回應 |
| 天災應變 | 颱風、疫情等突發事件対応 |

**關鍵指標**：異常恢復速度、危機處理滿意度

---

### 能力五：財務與數據分析能力

| 能力項目 | 說明 |
|---------|------|
| 每日結算 | 清楚掌握每日營收與支出 |
| 損益閱讀 | 能解讀財務報表，找出問題 |
| 成本概念 | 知道如何計算食材成本、毛利 |
| 談判能力 | 與供應商議價 |
| 數據應用 | 根據銷售數據調整備料 |

**關鍵指標**：月營收達成率、淨利率、迴轉天數

## 三、不同階段的店长要求

### 第一年：穩定型店长
- 重点：執行力、標準化、穩定出品
- 營收目標：達到基本損益平衡
- 優先任務：不犯錯、維持品質、建立團隊

### 第二~三年：成長型店长
- 重点：銷售提升、客群經營、成本優化
- 營收目標：提升營業額與淨利率
- 優先任務：提升來客數、開發新客、建立口碑

### 三年以上：策略型店长
- 重点：市場分析、資源整合、人才培养
- 營收目標：提升坪效、人效、擴大影響力
- 優先任務：優化流程、培訓幹部、建立系統

## 四、招募店长合作夥伴評估表

### 基本條件
- [ ] 有餐飲或零售業工作經驗（2年以上優先）
- [ ] 對手搖飲有熱情，願意長期投入
- [ ] 能配合假日及節日工作（飲料店假日生意最好）
- [ ] 具備機車或汽車代步工具
- [ ] 住在店面方圓30分鐘內

### 能力評估
- [ ] 面對壓力時能否保持冷静（情境題測試）
- [ ] 協調溝通能力（面試觀察）
- [ ] 學習意願與速度（過往經歷判斷）
- [ ] 價值觀與品牌理念是否契合

### 財務評估
- [ ] 能否提出一定比例的資金入股（展現承諾）
- [ ] 過去理財紀錄是否良好
- [ ] 是否有其他負債（影響判斷）

## 五、給投資者（老闆）的建議

### 適合的合作模式
1. **合夥人制度**：店长出资10-20%，盈餘分紅
2. **責任制**：設定績效目標，超額部分分红
3. **授權經營**：總部制定規範，店长负责执行

### 老闆的介入程度
- **適度介入的重點**：
  - 每週查看營收報表
  - 每月實地巡店1-2次
  - 每季與店长深度檢討
  - 重大決策（如展店、裝修、投資）需老闆同意

### 不需要介入的項目
- 每日排班、員工訓練、備料決策
- 促銷活動執行細節
- 顧客服務現場處理

## 六、結論

飲料店店长需要的是「韌性管理者」而非只是「執行者」。

在瞬變的餐飲市場，能存活下來的店长必需具備：
1. **穩定的執行力** - 做好每天的基本功
2. **靈活的應變力** - 面對突發狀況快速調整
3. **團隊的領導力** - 留住人才、建立文化
4. **務實的數字力** - 了解成本與獲利

尋找合作夥伴時，建議優先找有餐飲經驗且價值觀接近的人，資金多少不是唯一標準，願意投入與學習的態度更重要。
