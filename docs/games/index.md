## 🐍 蛇蛇大作戰

經典貪食蛇遊戲，手機優先設計！

### 如何玩

1. 點擊下方連結在瀏覽器中開啟遊戲
2. **手機用戶**：使用滑動手勢控制蛇的方向
3. **電腦用戶**：使用 `WASD` 或方向鍵控制

### 🎯 遊戲規則

- 🍎 吃蘋果：+10 分
- 💀 撞牆或撞自己：遊戲結束
- 🏆 挑戰最高分！
