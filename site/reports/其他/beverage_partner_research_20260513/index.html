    飲料店合作夥伴 / 店长招募研究報告¶

    研究日期： 2026年5月13日
    研究目的： 為老闆飲料店加盟計劃尋找合作夥伴/店长候選人
    截止日期： 2026年5月25日
    啟動時間： 2026年6-8月（春夏）

    1.3 餐飲相關 Facebook 社團（重要！）¶

    這些社團聚集了大量有經驗的餐飲從業人員，是尋找合作夥伴的好地方：

    1. 「餐飲創業聯盟」 - 適合找有創業意願的店长人選
    2. 「餐飲經驗交流區/飲料茶飲討論區」 - 適合找有飲料店經驗的人
    3. 「飲料店老闆/加盟主交流社團」 - 直接對接有興趣的投資者或加盟者
    4. 各縣市餐飲從業人員社團（如「台北餐飲工作機會」） - 適合找在職或轉職者

    操作方式： 在社團中發文說明合作模式，強調「投資者找合作店长」而非傳統雇用。

    1.4 餐飲同業與親友介紹¶

    • 透過飲料店原料供應商、設備商介紹（他們認識許多店家）
    • 參加餐飲加盟展（2026/6/12-15 台北世貿）面對面洽談
    • 在相關餐飲社群中低調詢問

    二、店长條件評估¶

    2.1 理想的店长候選人特質¶

    條件 重要性 說明
    餐飲管理經驗 ⭐⭐⭐⭐⭐ 至少有1-2年飲料店或餐飲業管理經驗
    熟悉飲料製作SOP ⭐⭐⭐⭐⭐ 能快速上手，降低訓練成本
    具備領導與排班能力 ⭐⭐⭐⭐ 需要管理2-4名員工
    穩定性高 ⭐⭐⭐⭐ 能長期投入，非短期打工心態
    熟悉在地商圈 ⭐⭐⭐ 熟悉台北/新店地區者優先
    有成本控管概念 ⭐⭐⭐ 避免浪費，提升利潤
    正面積極的服務態度 ⭐⭐⭐⭐ 直接影響顧客回流率

    2.2 台北飲料店店长薪資行情（2025-2026參考）¶

    類型 月薪範圍 說明
    一般飲料店店长 35,000～42,000元 連鎖體系，見 104 職缺
    知名連鎖品牌（如50嵐等） 40,000～50,000元 知名度高，薪資較有竞争力
    自創品牌/獨立店 32,000～40,000元 需要搭配分紅/獎金機制增加吸引力
    連鎖餐飲集團储備店长 40,000～55,000元 乐多多集团最高可达80k

    建議策略： 若定位為投資者合作模式，固定薪資可訂在 35,000-40,000區間，另設計績效獎金或營業額分紅，提高竞争力。

    2.3 激勵方案設計¶

    方案A：固定底薪 + 營業額分紅（推薦）¶

    • 底薪：35,000-40,000元/月
    • 營業額分紅：月營業額超過一定門檻後，店长可分得 3-5%
    • 優點：既能保障基本生活，又能激勵提升業績

    方案B：低底薪 + 高分紅¶

    • 底薪：28,000-32,000元/月
    • 淨利潤分紅：月淨利潤的 15-20% 分配給店长
    • 優點：降低固定人事成本，激勵效果強
    • 缺點：需建立透明財報制度

    方案C：股櫂激勵（長期綁定）¶

    • 店长表現滿一年後，給予 5-10% 的股份
    • 之後每年根據表現分配更多股份
    • 優點：長期留才，店长視為自己的事業
    • 參考：星巴克模式，讓員工成為合夥人

    三、合作模式選項¶

    3.1 各方案比較¶

    模式 投資者負擔 店长負擔 優點 缺點
    純雇用制 全部資金 不出資金 簡單明瞭 店长没有 ownership 感，容易跳槽
    固定底薪 + 分紅 大部分資金 不出資金 平衡保障與激勵 需要建立財報透明機制
    合夥經營 70-80% 20-30% 共同承担風險，绑在一起 需要法律文件，决策可能有分歧
    加盟品牌合作 品牌協助 品牌協助 有SOP支援，品牌自帶流量 加盟金高，抽成/權利金持續
    委託經營 全部資金 管理營運 投資者純出錢，店长全權管理 需設計監督機制

    老闆的情境，建議：

    「固定底薪 + 營業額分紅 + 股櫂激勵」三合一模式 - 底薪保障基本生活（35,000-40,000元） - 營業額分紅激勵短期表現 - 股櫂獎勵長期留才（满1年配股）

    3.2 合夥協議書核心條款建議¶

    若採用合夥模式，建議包含以下條款： 1. 出资比例與利潤分配（白紙黑字） 2. 各自負責範圍（投資者不出門店管理，店长負責日常營運） 3. 盈虧處理方式（前半年或一年是否為評估期） 4. 退出機制（如何結算、轉讓股份） 5. 競業禁止條款（合夥期間及结束後1年內不得經管同類業務） 6. 决策機制（重大开支、促銷活動如何決定）

    台北市核心商圈¶

    商圈 優點 缺點 適合類型
    西門町 人潮超大，觀光客多 租金極高（月租可達30萬+） 高單價特色茶飲
    東區（大安區） 2025年租金回温，人潮穩定 租金仍高 中高價位飲品
    士林夜市 觀光人潮穩定 租金波動大，空置率高 平價手搖飲
    師大夜市 學生族群穩定 2025年租金爆涨，單坪破萬 中價位
    信義區（市政府/101） 白領上班族多 租金極高 高單價創意飲品

    新北新店區（建議重點關注）¶

    位置 優勢 說明

    七張站周邊 住宅與學生族群 生活機能佳

    4.2 租金行情參考（2025-2026）¶

    區域 每坪月租 適用坪數 評估
    台北市精華商圈（西門町/東區） 8,000-15,000元/坪 15-30坪 租金壓力大，月租可能達20-40萬
    師大/士林夜市 5,000-10,000元/坪 15-25坪 中等壓力
    新店市區（捷運站周邊） 2,000-5,000元/坪 15-25坪 ✅ 壓力較小，CP值高
    新店光明街/碧潭 2,500-4,500元/坪 15-25坪 ✅ 適合初創

    2026年創業建議： 租金總成本建議控制在月營業額的 15-20% 以內。選擇新店等區域可大幅降低固定成本，提高生存率。

    4.3 競爭對手分布¶

    台灣手搖茶市場竞争激烈，主要品牌： - 50嵐（已停止加盟，只剩直營） - 迷客夏（加盟金約60-100萬） - 可不可紅茶（加盟金約40-70萬） - 麻古茶坊（高單價策略） - 清心福全（大型連鎖） - 一沐日、你好鹽水等（特色小店）

    建議策略： 自創品牌或加入中小型連鎖體系，降低加盟金負擔，同時保有差異化空間。

    六、額外資源與建議¶

    6.1 參加實體活動¶

    • 2026/6/12-15 第18屆台北國際連鎖加盟創業展（台北世貿）
    • 現場有多家飲料品牌參展
    • 可直接洽談加盟機會，也能遇見有興趣的合作夥伴
    • 建議先網路預約登記，現場掃描名片

    6.2 供應商人脈¶

    飲料設備供應商、原料供應商（如茶葉、糖漿廠商）通常認識很多飲料店老闆，可以請他們介紹合作夥伴。

    6.3 風險提示¶

    1. 人手不足的替代方案： 若真的找不到合适店长，可考慮先以「工讀生 + 短期管理」方式營運，同時繼續招募
    2. 商圈選擇要謹慎： 避免只看人潮，要評估平日與假日的穩定客源
    3. 合作協議要明確： 任何口頭承諾都要白紙黑字，避免日後糾紛

    結論¶

    老闆的計劃（投資者角色，6-8月啟動，截止日5/25）是可行的。建議：

    1. 立即行動： 在104、1111、FB社團同步展開招募
    2. 強調差異化： 招募內容突顯「合作夥伴模式」而非傳統雇用，讓有能力的从业者願意考虑
    3. 考慮新店區： 作為第一個據點，租金壓力小，人潮穩定
    4. 搭配激勵方案： 以「底薪+分紅+股櫂」三合一增加吸引力
    5. 備案準備： 若截止日未找到合适人選，可考慮延長招募或參加加盟展
